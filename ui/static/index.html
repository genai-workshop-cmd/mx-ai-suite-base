What happens next

The orchestration agent reads your material, classifies each requirement (config, customisation, integration, workflow, report) and routes the run to Agent 3A, Agent 3B, or both.

Each agent then searches the AI Brain for prior art, validates every Maximo name against the connected environment or the bundled 401-schema catalogue, and stops at a user gate. No phase starts until you approve the one before it.
